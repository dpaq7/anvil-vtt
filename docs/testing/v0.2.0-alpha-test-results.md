## Bugs & Issues Found

### Cosmetic / Low Priority

1. **Ability IDs shown instead of names** (Hero Sheet)
   - Abilities display raw compendium IDs like `mcdm.heroes.v1:feature.ability.null.1st-level-feature:faster-than-the-eye`
   - Should resolve to human-readable names like "Faster Than the Eye"
   - **Severity:** Low (cosmetic)
   - **Fix:** Add ability name resolution in HeroLogic or the hero sheet component

2. **"null" in hero class subheader**
   - Hero sheet shows "null — metakinetic · Level 1" instead of class name
   - The `heroClass` field isn't populated in the hero data
   - **Severity:** Low (cosmetic)
   - **Fix:** Ensure heroClass is populated during hero creation or display fallback

3. **Negotiation +Int/-Int don't visually update without WebSocket**
   - The Interest/Patience track buttons fire WS messages but UI doesn't optimistically update
   - **Severity:** Low (expected — state comes from server via WS)
   - **Fix:** Consider optimistic UI updates for better responsiveness

### Environment / Dev Tooling

4. **WebSocket 500 through Vite proxy**
   - Vite's proxy can't forward WS upgrades to wrangler dev Durable Objects
   - Direct WS to :8787 works fine (101 upgrade)
   - **Severity:** Medium (blocks local WS testing)
   - **Workaround:** Test WS features in deployed environment or bypass proxy
   - **Potential fix:** Configure vite proxy to use a different WS target path, or use direct WS connection to :8787 in dev mode

## Conclusion

The v0.2.0 alpha is in excellent shape. **51 of 54 tests passed** with 3 blocked by a local dev environment WebSocket proxy limitation (not a code bug). All core features work:

- Complete session lifecycle (create → lobby → play → end)
- All 4 testable scene types render correctly (battle, story, negotiation, respite)
- Battle map with full toolbar (7 tools), zoom controls, and grid overlay
- Audio player with play/pause, loop, mute, volume, and track selection
- Rich text note editor with full formatting toolbar
- Hero sheet with vitals, characteristics, skills, and abilities
- Director and Player navigation modes with role switching
- Proper error handling for invalid routes and sessions
- Responsive sidebar collapse

**Recommended next steps:**
1. Fix hero ability name resolution (cosmetic)
2. Fix "null" class name in hero subheader (cosmetic)
3. Investigate Vite WS proxy issue or add dev-mode direct WS connection
4. Add montage scene test data to verify montage rendering
5. Deploy to staging to test full WebSocket real-time sync
